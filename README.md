# 🧠 Discord Brain Bot

Ένα έξυπνο, αυτόνομο Discord Bot που λειτουργεί ως προσωπικός βοηθός (Second Brain). Διαβάζει, "θυμάται" τις προσωπικές σου σημειώσεις από συγκεκριμένα κανάλια του server και σου απαντάει σε πραγματικό χρόνο συνδυάζοντας όλες τις πληροφορίες που του έχεις δώσει, αξιοποιώντας το τεράστιο context window του **Gemini 3.8 Flash**.

## 🏗️ Αρχιτεκτονική (In-Memory Full Context)

Αρχικά το project ξεκίνησε χρησιμοποιώντας μια βάση δεδομένων Vector (ChromaDB) και τεχνικές Embedding. Ωστόσο, αναβαθμίστηκε σε μια πολύ πιο αποδοτική, γρήγορη και ανέξοδη αρχιτεκτονική ("In-Memory Full Context") για τους εξής λόγους:

1. **Ασύμβατο με το Render:** Οι δωρεάν servers (όπως το Render) διαγράφουν τον δίσκο σε κάθε επανεκκίνηση. Η βάση δεδομένων στην ουσία χανόταν κάθε μέρα.
2. **API Limits:** Το δωρεάν πακέτο της Google επιτρέπει μόνο 1500 embeddings (μετατροπές κειμένου) τη μέρα. Όταν περνούσαμε τις σημειώσεις μαζικά, ο κώδικας χτυπούσε το όριο (Error 429) και κράσαρε.
3. **Τεράστια Μνήμη Gemini:** Το νέο μοντέλο της Google (Gemini Flash) υποστηρίζει **1.000.000 tokens**. Αυτό σημαίνει ότι μπορεί να διαβάσει με τη μία ένα ολόκληρο βιβλίο. Έτσι, καταργήσαμε τη βάση και απλά του δίνουμε όλες τις σημειώσεις κατευθείαν στην ερώτηση!

### Πώς λειτουργεί πλέον:
* **Αυτόματη Φόρτωση:** Μόλις το bot συνδεθεί (`on_ready`), διαβάζει τα τελευταία 2000 μηνύματα από τα επιλεγμένα κανάλια-σημειώσεις και τα αποθηκεύει στη μνήμη RAM του (ως μια απλή λίστα). Δεν χρειάζεται καμία εντολή `!sync`.
* **Ζωντανή Ενημέρωση:** Αν γράψεις ένα νέο μήνυμα στα κανάλια-σημειώσεις, το bot το "ακούει" (`on_message`) και το προσθέτει αθόρυβα στη μνήμη του την ίδια στιγμή.
* **Απαντήσεις με Context:** Όταν μιλάς στο κανάλι συζήτησης (π.χ. `#chat`), το bot μαζεύει όλες τις σημειώσεις από τη μνήμη του και τις στέλνει μαζί με την ερώτησή σου στο Gemini API. Σου απαντάει άμεσα, γνωρίζοντας όλο το ιστορικό σου!

## ⚙️ Ρυθμίσεις (Environment Variables)

Για να τρέξει σωστά στο Render, πρέπει να οριστούν τα εξής Environment Variables:
* `DISCORD_TOKEN`: Το token του Discord Bot σου.
* `GEMINI_API_KEY`: Το κλειδί για το Google Gemini API.
* `CHAT_CHANNEL_ID`: Το ID του καναλιού στο οποίο θα μιλάς με το bot (εκεί που θα σου απαντάει).
* `TARGET_CHANNEL_IDS`: Τα IDs των καναλιών από τα οποία το bot θα διαβάζει τις σημειώσεις (χωρισμένα με κόμμα, π.χ. `1234567,9876543`).

## 🚀 Deploy στο Render

1. Σύνδεσε το project από το GitHub ως **Web Service**.
2. **Start Command:** Βάλε `python -u bot.py` (το `-u` μας βοηθάει να βλέπουμε αμέσως τυχόν σφάλματα στα Logs).
3. Βάλε τα Environment Variables.
4. Ο κώδικας περιέχει ήδη έναν "Mini Web Server" (`SimpleHandler`) στη θύρα 8080, ώστε το Render να βλέπει ότι η υπηρεσία είναι ζωντανή και να περνάει επιτυχώς τα Health Checks (χωρίς Timeout).

## 📂 Αρχεία

* `bot.py`: Ολόκληρη η λογική, η διαχείριση μνήμης και η επικοινωνία με Discord & Google API.
* `requirements.txt`: Εξαιρετικά ελαφρύ. Περιέχει μόνο τα απαραίτητα (`discord.py` και `google-genai`).
